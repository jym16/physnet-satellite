# Physical Networks Satellite Archive

This repository contains the public website and static archive for the **Physical Networks** NetSci satellite series.

The site is built with [Quarto](https://quarto.org/). Edition pages are generated from YAML data files so that yearly updates can be made by editing structured metadata and replacing image assets.

## Contents

```text
.
├── index.qmd                  # Generated home page
├── archive.qmd                # Generated archive index
├── program.qmd                # Generated pointer to the latest archived program
├── links.qmd              # Links to original public source pages
├── editions/                  # Generated edition pages
│   ├── 2023/
│   ├── 2024/
│   ├── 2025/
│   └── 2026/
├── data/
│   ├── series.yml             # Series-level settings and homepage mode
│   ├── editions.yml           # Generated compact edition index
│   ├── editions.json          # Generated compact edition index
│   └── editions/              # Source-of-truth edition metadata
│       ├── 2023.yml
│       ├── 2024.yml
│       ├── 2025.yml
│       └── 2026.yml
├── templates/                 # Jinja templates for generated pages
├── scripts/                   # Page generation, validation, landing-image generation
├── assets/
│   ├── styles.css             # Site styling
│   └── img/                   # Logos, landing images, speaker images, and visual assets
└── sources/                   # Additional archival notes and source material
```

## Editing workflow

Edit source files, then regenerate pages:

```bash
python scripts/validate_data.py
python scripts/generate_landing_images.py --all
python scripts/build_pages.py
quarto preview
```

The main source files are:

```text
data/series.yml
data/editions/YYYY.yml
assets/img/YYYY/
assets/img/common/logos/
templates/*.qmd.j2
assets/styles.css
```

Generated files should not be edited directly. Each generated `.qmd` file includes a comment at the top indicating its source data and template.

## Homepage mode

The homepage is controlled by `data/series.yml`:

```yaml
home:
  mode: "archive"      # "archive" or "current"
  current_year: null   # set to a year when mode is "current"
  latest_year: 2026
```

Use `mode: "current"` while promoting an upcoming or active edition. Use `mode: "archive"` after the edition has concluded.

## Landing images

Landing-title images are generated by:

```bash
python scripts/generate_landing_images.py --all
```

The script creates both left-logo and right-logo variants for each edition and for the series homepage under:

```text
assets/img/common/landing/
```

## Editions

The archive currently includes:

- **Physical Networks I**, NetSci 2023
- **Physical Networks II**, NetSci 2024
- **Physical Networks III**, NetSci 2025
- **Physical Networks IV**, NetSci 2026

The repository is intended as a public-facing website and archive. Private organizing material and personal contact information should not be stored here.


## Data-driven workflow

Edition pages and the homepage are generated from YAML files under `data/` and templates under `templates/`. Edit the relevant YAML file and local image assets, then regenerate the pages with the scripts in `scripts/`.
