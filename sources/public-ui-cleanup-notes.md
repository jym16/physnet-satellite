# Public UI cleanup notes

This update addresses four public-site issues:

1. The contributed-talk application button is no longer clickable and is shown as a disabled "Application period closed" control.
2. Keyword chips now wrap safely when a long keyword has no natural line break.
3. Organizing committee entries no longer show personal email links.
4. The duplicate top-right code icon was removed, leaving only the GitHub repository icon.

The stylesheet was also renamed from `assets/styles.scss` to `assets/styles.css` to avoid deployment differences on GitHub Pages.
